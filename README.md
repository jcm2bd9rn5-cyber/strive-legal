# Strive Legal

**Strive のための法的情報・ライセンス情報管理サイト**

---

## 概要

Strive アプリに関連する法的情報、プライバシーポリシー、利用規約、ライセンス情報を一元管理するウェブサイトです。

---

## 主な内容

- 📋 **利用規約（Terms of Service）**
- 🔐 **プライバシーポリシー（Privacy Policy）**
- 📜 **ライセンス情報**
- ⚖️ **法的表記**

---
